# Sac Luxe — Next.js

Next.js (App Router) rebuild of https://storefront-spark-34.lovable.app

## Run
```
npm install
npm run dev
```
Open http://localhost:3000

## Images
Images load from the original site by default. To host them locally:
1. `npm run images`
2. Set `BASE = ""` in `lib/data.js`

Content (products, slides, text) lives in `lib/data.js`.
